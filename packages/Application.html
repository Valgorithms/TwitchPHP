Table of Contents

Classes

Command
One registered chat command for the {@see CommandClient}: a name, its handler, and the gates around it (aliases, a per-user cooldown, a permission level).
CommandClient
A richer command layer over {@see Irc} — the equivalent of DiscordPHP's `MessageCommandClient`. It listens to the client's `command` event (which {@see Irc} already emits for `<prefix><name> …`) and adds aliases, per-user cooldowns, permission levels and an auto-generated `help` command.
Irc
The Twitch chat client over the WebSocket IRC gateway (`wss://irc-ws.chat.twitch.tv`).
EventSub
The EventSub WebSocket transport (`wss://eventsub.wss.twitch.tv/ws`).
SubscriptionTypes
Every EventSub subscription type string, plus the version Twitch currently expects for it. {@see EventSub::subscribe()} looks the version up here when one is not given, so callers never have to remember that `channel.follow` is `2` while everything around it is `1`.
Factory
Hydrates {@see Part}s (and, less often, {@see AbstractRepository}s) from decoded Helix payloads. Every part is handed the {@see Twitch} client so it can reach the HTTP layer and build nested parts.
BannedUser
A banned or timed-out user (`GET /helix/moderation/banned`, response of `POST /helix/moderation/bans`).
BitsLeaderboardEntry
One row of the Bits leaderboard (`GET /helix/bits/leaderboard`).
BlockedTerm
An AutoMod blocked term (`GET`/`POST`/`DELETE /helix/moderation/blocked_terms`).
Channel
A channel's broadcast information (`GET /helix/channels`).
ChannelSearchResult
A hit from `GET /helix/search/channels` — a channel that matches the query, live or not.
CharityCampaign
A running charity campaign (`GET /helix/charity/campaigns`).
CharityDonation
A single donation to a charity campaign (`GET /helix/charity/donations`).
ChatBadge
A chat badge set and its versions (channel or global badges).
ChatMessage
A parsed chat `PRIVMSG` from the IRC gateway.
ChatSettings
A channel's chat settings (`GET`/`PATCH /helix/chat/settings`).
Chatter
A user currently connected to a channel's chat (`GET /helix/chat/chatters`).
Cheermote
A Cheermote set (`GET /helix/bits/cheermotes`).
Clip
A clip (`GET /helix/clips`).
Conduit
An EventSub conduit (`GET/POST/PATCH/DELETE /helix/eventsub/conduits`) — a durable, shardable transport that many subscriptions can point at.
ContentClassificationLabel
A Content Classification Label (`GET /helix/content_classification_labels`) — the tags a broadcaster can apply to a stream (`DrugsIntoxication`, `Gambling`, …).
CustomReward
A channel-points custom reward (`GET/POST/PATCH/DELETE /helix/channel_points/custom_rewards`).
DropsEntitlement
A Drops entitlement (`GET/PATCH /helix/entitlements/drops`).
Emote
A chat emote (channel, global, set, or user emotes).
EventSubSubscription
An EventSub subscription record (`GET/POST/DELETE /helix/eventsub/subscriptions`).
Game
A game / category (`GET /helix/games`, `GET /helix/games/top`).
Goal
A creator goal (`GET /helix/goals`).
HypeTrainEvent
A Hype Train event (`GET /helix/hypetrain/events`).
Moderator
A channel moderator or VIP (`GET /helix/moderation/moderators`, `GET /helix/channels/vips`) — both share this shape.
Part
Base model for a single Twitch Helix entity.
Poll
A poll (`GET/POST/PATCH /helix/polls`).
Prediction
A channel-points prediction (`GET/POST/PATCH /helix/predictions`).
RewardRedemption
A redemption of a custom reward (`GET/PATCH /helix/channel_points/custom_rewards/redemptions`).
Schedule
A channel's stream schedule (`GET /helix/schedule`) — a single object with a list of {@see ScheduleSegment}-shaped rows and an optional vacation window.
ScheduleSegment
One entry in a channel's stream schedule (`POST/PATCH/DELETE /helix/schedule/segment`).
Stream
A live stream (`GET /helix/streams`).
Subscription
A broadcaster subscription (`GET /helix/subscriptions`) or the authenticated user's subscription to a channel (`GET /helix/subscriptions/user`).
Team
A Twitch team (`GET /helix/teams`, `GET /helix/teams/channel`).
User
A Twitch user (`GET /helix/users`).
Video
A video / VOD (`GET /helix/videos`).
AbstractRepository
A live, lazily-populated view of one Helix resource collection — the same shape as a DiscordPHP repository: an in-memory {@see Collection} of hydrated {@see Part}s plus async `freshen` / `fetch` / `save` / `delete` against the bound endpoints.
AdsRepository
The channel-ads resource — start a commercial (`channel:edit:commercial`), read the ad schedule and snooze the next mid-roll (`channel:manage:ads` / `channel:read:ads`).
AnalyticsRepository
The `analytics/*` resource — signed download URLs for extension and game analytics CSV reports (`analytics:read:extensions` / `analytics:read:games`).
BitsRepository
The `bits/*` resource — the Bits leaderboard (`bits:read`) and the Cheermote catalogue (global + a channel's custom set).
ChannelPointsRepository
The Channel Points resource — custom rewards (`channel:read:redemptions` / `channel:manage:redemptions`) and their redemption queue. Only rewards this Client-ID created are manageable.
ChannelRepository
The `channels` resource — broadcast info, the modify call, editors, and the followers / followed lists.
CharityRepository
The `charity/*` resource (`channel:read:charity`) — the broadcaster's active charity campaign and its donations.
ChatRepository
The Helix `chat/*` resource group — settings, chatters, emotes, badges, announcements, shoutouts, sending a message, and per-user colour.
ClipRepository
The `clips` resource — look clips up by id / broadcaster / game, and create one from the running stream.
ConduitRepository
The `eventsub/conduits` resource — conduits and their shards. App-access-token only. A conduit lets one durable transport back many EventSub subscriptions; shards spread the delivery load.
ContentClassificationRepository
The `content_classification_labels` resource — the CCL catalogue, localised.
EntitlementRepository
The `entitlements/drops` resource — list a game's / user's Drops entitlements and mark them fulfilled. App or user token (a user token scopes the results to that user).
EventSubSubscriptionRepository
The `eventsub/subscriptions` REST resource — the durable subscription list for both webhook and WebSocket transports. The {@see \Twitch\EventSub\EventSub} WebSocket client uses `subscribe()` for its own session; this repository is for listing, auditing and deleting subscriptions out of band.
ExtensionRepository
The `extensions/*` and `users/extensions` resources — a user's installed extensions and their active slots, an extension developer's own version metadata, live channels running an extension, and Bits transactions.
GameRepository
The `games` resource — lookup by id / name / IGDB id, and the top-games chart.
GoalRepository
The `goals` resource (`channel:read:goals`) — a broadcaster's active creator goals (follower / subscriber / …). Read-only via the API.
GuestStarRepository
The `guest_star/*` resource (**beta**) — channel settings, the live session, invites and slots. Scopes are `channel:read:guest_star` / `channel:manage:guest_star` (or the `moderator:` equivalents).
HypeTrainRepository
The `hypetrain/events` resource (`channel:read:hype_train`) — the recent Hype Train history for a broadcaster. Read-only.
ModerationRepository
The Helix `moderation/*` and related resources — bans and timeouts, moderators, VIPs, blocked terms, message deletion, Shield Mode, warnings.
PollRepository
The `polls` resource (`channel:read:polls` / `channel:manage:polls`) — list, open and end a channel poll.
PredictionRepository
The `predictions` resource (`channel:read:predictions` / `channel:manage:predictions`) — list, open, lock and resolve a channel-points prediction.
RaidRepository
The `raids` resource (`channel:manage:raids`) — start or cancel a raid from the broadcaster's channel to another. There is no list endpoint, so this repository is action-only.
ScheduleRepository
The stream-schedule resource — read a channel's schedule (`GET /helix/schedule`), and, as the broadcaster (`channel:manage:schedule`), toggle vacation mode and add / edit / remove individual segments.
SearchRepository
The `search/*` resource — search categories (games) and channels by name. No scope required.
StreamRepository
The `streams` resource — live streams, followed streams, the stream key, and stream markers.
SubscriptionRepository
The `subscriptions` resource — a broadcaster's subscriber list (`channel:read:subscriptions`) and the "does this user sub to that channel?" check (`user:read:subscriptions`).
TeamRepository
The `teams` resource — a team by name or id (with its full member list), and the teams a channel belongs to (without members).
UserRepository
The `users` resource — lookups by id / login, the authenticated user, the description update, and the block list.
VideoRepository
The `videos` resource — VODs / highlights / uploads by id, user or game, and deletion.
WhisperRepository
The `whispers` resource (`user:manage:whispers`) — send a whisper as the authenticated user. Send-only; there is no read endpoint. The sender must have a verified phone number and (for the first whisper to a user) they must not have whispers blocked.
Twitch
The Twitch client — the same role `Discord\Discord` plays under DiscordPHP.
