implements EventEmitterInterface uses EventEmitterTrait

Twitch.php : 76

The Twitch client — the same role `Discord\Discord` plays under DiscordPHP.

Owns the OAuth token lifecycle, the Http transport, the Factory, the resource repositories ($twitch->users, $twitch->streams, …), and, when configured, the EventSub WebSocket and the Irc chat client. Emits init / ready once authenticated and set up.
