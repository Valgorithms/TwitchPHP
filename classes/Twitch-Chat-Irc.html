The Twitch chat client over the WebSocket IRC gateway (`wss://irc-ws.chat.twitch.tv`).

Handles the CAP/PASS/NICK handshake, PING/PONG, channel membership, and IRCv3 tag parsing. Chat messages surface on the Twitch client as the chat event carrying a ChatMessage; a message beginning with the command prefix also fires command and any handler registered with registerCommand() — the small equivalent of DiscordPHP's MessageCommandClient.
