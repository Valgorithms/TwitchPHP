DeviceCodeReauthorizer.php : 41

Re-authorizes through the OAuth device-code flow.

Needs no redirect URI and no local HTTP listener: it asks Twitch for a short user code, hands that to a prompt callback for display, then polls until the user approves or the code expires.

The prompt is injected rather than printed so the flow works wherever the client runs — echo from a CLI, a DM from a bot, a desktop notification:

new DeviceCodeReauthorizer($oauth, $scopes, function (array $device): void {
    printf("go to %s and enter %s\n", $device['verification_uri'], $device['user_code']);
});
