ModerationRepository extends AbstractRepository
in package
  • Application

ModerationRepository.php : 32

The Helix `moderation/*` and related resources — bans and timeouts, moderators, VIPs, blocked terms, message deletion, Shield Mode, warnings.

Every call takes an explicit $broadcasterId and (where the API requires it) a $moderatorId; the authenticated user must be that moderator.
