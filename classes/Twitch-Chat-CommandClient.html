CommandClient
in package
  • Application

FinalYes
CommandClient.php : 32

A richer command layer over {@see Irc} — the equivalent of DiscordPHP's `MessageCommandClient`. It listens to the client's `command` event (which {@see Irc} already emits for `<prefix><name> …`) and adds aliases, per-user cooldowns, permission levels and an auto-generated `help` command.

$cc = new CommandClient($twitch);
$cc->command('so', function (ChatMessage $m, array $args) use ($twitch) {
    $twitch->chat->shoutout($m->tags['room-id'], $args[0], $twitch->getUserId());
}, permission: Command::MODERATOR, cooldown: 30, description: 'Shout out a channel');
